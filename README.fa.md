# استودیو آمادگی مصاحبه

### آمادگی مصاحبه با قدرت هوش مصنوعی — سوالات، فلش‌کارت‌ها، مصاحبه‌های تقلیدی و بیشتر

یک پلتفرم فراوان آمادگی مصاحبه ساخته‌شده با Next.js 16، با مربیگری هوش مصنوعی سه‌تأمین‌کننده (OpenAI، Anthropic، Gemini)، فلش‌کارت‌های تکرار فاصله‌دار، مصاحبه‌های تقلیدی، چالش‌های کدنویسی، تحلیل‌های پیشرفت و سیستمเกม‌سازی — هرچه توسط شرکت و رشته یادگیری سازمان‌دهی شده.

## Overview

استودیو آمادگی مصاحبه یک پلتفرم یادگیری شبیه Duolingo برای مصاحبه‌های مهندسی نرم‌افزار است. این پلتفرم بانک سوالات عظیم، مربیگری و ارزیابی با قدرت هوش مصنوعی، فلش‌کارت‌های تکرار فاصله‌دار، شبیه‌سازی‌های مصاحبه تقلیدی و ردیابی پیشرفت بازی‌سازی‌شده را ترکیب می‌کند — همگی از طریق داشبوردی تکمیل با ناوبری پالت دستور.

## معماری هوش مصنوعی

```
ورودی کاربر → لایه انتزاع ارائه‌کننده
    ├── OpenAI (gpt-4o، gpt-4o-mini)
    ├── Anthropic Claude (claude-sonnet)
    └── Google Gemini (gemini-2.0-flash)
    ↓
پاسخ متحد → مربی / ارزیاب / تولیدکننده
```

لایه انتزاع `lib/ai/provider.ts` انتقال‌پذیری بین ارائه‌کنندگان را با یک رابط واحد ممکن می‌سازد، که منطق فیل‌بک و بهینه‌سازی‌های خاص ارائه‌کننده را فعال می‌کند.

## شروع سریع

### پیش‌نیازها

- **Node.js** >= 18.0.0

### نصب

```bash
git clone https://github.com/mohammadhossein-asadi/interview-prep-studio.git
cd استودیو-آمادگی-مصاحبه
npm install
```

### پیکربندی محیط

یک فایل `.env.local` ایجاد کنید:

```env
NEXTAUTH_SECRET="your-secret"
NEXTAUTH_URL="http://localhost:3000"
OPENAI_API_KEY="sk-..."
ANTHROPIC_API_KEY="sk-ant-..."
GOOGLE_GEMINI_API_KEY="..."
```

### توسعه

```bash
npm run dev
```

### بیلد تولید

```bash
npm run build
npm run start
```

## تصمیمات کلیدی معماری

### انتزاع ارائه‌کننده هوش مصنوعی متحد

`lib/ai/provider.ts` یک رابط واحد را برای همه سه ارائه‌کننده هوش مصنوعی ایجاد می‌کند، که انتخاب thờiگن_runtime، فیل‌بک خودکار و فرمت‌دهی پاسخ متحد را در задач‌های مربیگری، ارزیابی و تولید فعال می‌کند.

### الگوریتم تکرار فاصله‌دار

اجرا سفارشی الگوریتم SM-2 (که توسط Anki استفاده می‌شود) در `lib/spaced-repetition.ts` با انواع TypeScript برای کارت‌ها، بازبینی‌ها و پارامترهای زمان‌بندی.

### گروه‌های مسیر برای جداسازی چیدمان

گروه‌های مسیر Next.js 16 (`(auth)`، `(market)`، `(داشبورد)`) دغدغه‌های چیدمان را بدون تأثیر بر ساختار URL به وضوح جدا می‌کنند.

### بخش‌بندی فروشگاه Zustand

۸ فروشگاه متمرکز (احراز، سوالات، فلش‌کارت‌ها، پیشرفت، ui، و غیره) دوباره‌سازی‌های غیرضروری را جلوگیری کرده و منطق حالت را با ویژگی‌ها هم‌موقع نگه می‌دارد.
